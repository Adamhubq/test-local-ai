## 7. Адаптивное поведение

### Контрольные диапазоны ширины
| Устройство | Ширина экрана | Описание |
|------------|---------------|----------|
| Mobile (XS) | 0 - 575px | Мобильные устройства с маленькими экранами |
| Tablet (SM) | 576px - 767px | Планшеты и большие мобильные устройства |
| Desktop (MD) | 768px - 991px | Настольные компьютеры и планшеты в горизонтальном положении |
| Desktop (LG) | 992px - 1199px | Настольные компьютеры с большими экранами |
| Desktop (XL) | 1200px - 1399px | Настольные компьютеры с очень большими экранами |
| Desktop (XXL) | 1400px+ | Очень большие мониторы и телевизоры |

### Правила перестроения сетки
1. **XS (0 - 575px)**: 1 колонка, максимальная ширина контента
2. **SM (576px - 767px)**: 2 колонки, адаптивная ширина
3. **MD (768px - 991px)**: 3 колонки, фиксированная ширина
4. **LG (992px - 1199px)**: 4 колонки, фиксированная ширина
5. **XL (1200px - 1399px)**: 5 колонок, фиксированная ширина
6. **XXL (1400px+)**: 6 колонок, фиксированная ширина

### Touch-friendly размеры элементов
- Минимальный размер нажатия: 44px x 44px
- Интервал между элементами: не менее 8px
- Отступы от краев экрана: не менее 16px
- Размер шрифта: не менее 16px для основного текста

## 9. Правила реализации

Все визуальные правила реализованы через централизованные design tokens, что обеспечивает:
- Единую цветовую палитру и типографику
- Согласованность интерфейса на всех устройствах
- Легкость обновления и поддержки
- Адаптивность через медиа-запросы и переменные CSS

Все компоненты используют переменные CSS для цветов, отступов, размеров шрифтов и теней, что позволяет легко изменять визуальный стиль проекта без изменения кода компонентов.
