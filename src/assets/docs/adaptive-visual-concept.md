# Адаптивная визуальная концепция NOVA STORE

## Общие принципы

NOVA STORE использует адаптивный дизайн с мобильным-first подходом. Все компоненты интерфейса адаптируются под разные устройства и размеры экрана, обеспечивая оптимальное пользовательское взаимодействие на всех платформах.

## Контрольные диапазоны ширины

| Устройство | Ширина экрана | Описание |
|------------|---------------|----------|
| Mobile (XS) | 0 - 575px | Мобильные устройства с маленькими экранами |
| Tablet (SM) | 576px - 767px | Планшеты и большие мобильные устройства |
| Desktop (MD) | 768px - 991px | Настольные компьютеры и планшеты в горизонтальном положении |
| Desktop (LG) | 992px - 1199px | Настольные компьютеры с большими экранами |
| Desktop (XL) | 1200px - 1399px | Настольные компьютеры с очень большими экранами |
| Desktop (XXL) | 1400px+ | Очень большие мониторы и телевизоры |

## Ключевые паттерны

### 1. Шапка (Header)

**Mobile (XS):**
- Логотип слева, кнопки действий справа
- Навигационное меню в виде бургер-меню
- Поиск в отдельной строке
- Высота шапки: 60px
- Отступы: 16px от краев экрана

**Tablet (SM):**
- Логотип слева, навигация по центру, кнопки действий справа
- Поиск в строке навигации
- Высота шапки: 70px
- Отступы: 24px от краев экрана

**Desktop (MD/LG/XL/XXL):**
- Логотип слева, навигация по центру, кнопки действий справа
- Поиск в строке навигации
- Высота шапки: 80px
- Отступы: 32px от краев экрана

### 2. Меню (Navigation)

**Mobile (XS):**
- Бургер-меню с вертикальным списком
- Высота пунктов меню: 50px
- Интервал между пунктами: 1px
- Анимация открытия/закрытия

**Tablet (SM):**
- Горизонтальное меню с выпадающими подменю
- Пункты меню с отступами 24px
- Высота меню: 60px

**Desktop (MD/LG/XL/XXL):**
- Горизонтальное меню с выпадающими подменю
- Пункты меню с отступами 32px
- Высота меню: 70px

### 3. Поиск

**Mobile (XS):**
- Поле поиска в виде отдельной строки
- Размер кнопки поиска: 44px x 44px
- Отступы: 16px от краев экрана

**Tablet (SM):**
- Поле поиска в строке навигации
- Размер кнопки поиска: 50px x 50px
- Отступы: 24px от краев экрана

**Desktop (MD/LG/XL/XXL):**
- Поле поиска в строке навигации
- Размер кнопки поиска: 56px x 56px
- Отступы: 32px от краев экрана

### 4. Каталог (Catalog)

- Интервал между карточками: 24px
- Размер карточки: 48% ширины экрана
- Высота карточки: 450px

**Desktop (MD/LG/XL/XXL):**
- Сетка 3 колонки
- Интервал между карточками: 32px
- Размер карточки: 32% ширины экрана
- Высота карточки: 500px

### 5. Карточки товаров (Product Cards)

### 6. Фильтры (Filters)

**Mobile (XS):**
- Сворачиваемые фильтры в модальном окне
- Высота фильтра: 100% высоты экрана
- Интервал между элементами: 16px

**Tablet (SM):**
- Горизонтальные фильтры с прокруткой
- Высота фильтра: 80px

**Desktop (MD/LG/XL/XXL):**

- Высота фильтра: 100% высоты контента
- Интервал между элементами: 32px

### 7. Модальные окна (Modals)

**Mobile (XS):**
- Полноэкранное модальное окно
- Высота: 100% экрана
- Отступы: 16px от краев экрана
- Размер кнопок: 44px x 44px

**Tablet (SM):**
- Модальное окно с отступами от краев экрана
- Высота: 80% экрана
- Отступы: 24px от краев экрана
- Размер кнопок: 50px x 50px

**Desktop (MD/LG/XL/XXL):**
- Модальное окно с отступами от краев экрана
- Высота: 60% экрана

- Размер кнопок: 56px x 56px

### 8. Нижняя навигация (Bottom Navigation)

**Mobile (XS):**
- Скрыта на мобильных устройствах
- Используется только в специфических сценариях

**Tablet (SM):**
- Отображается как дополнительная панель навигации
- Высота: 60px
- Интервал между элементами: 16px

**Desktop (MD/LG/XL/XXL):**
- Не отображается на десктопах
- Используется только на мобильных устройствах в специфических сценариях

## Правила перестроения сетки

### Mobile-first подход:
1. **XS (0 - 575px)**: 1 колонка, максимальная ширина контента
2. **SM (576px - 767px)**: 2 колонки, адаптивная ширина
3. **MD (768px - 991px)**: 3 колонки, фиксированная ширина
4. **LG (992px - 1199px)**: 4 колонки, фиксированная ширина
5. **XL (1200px - 1399px)**: 5 колонки, фиксированная ширина
6. **XXL (1400px+)**: 6 колонок, фиксированная ширина

### Touch-friendly размеры элементов:
- Минимальный размер нажатия: 44px x 44px
- Интервал между элементами: не менее 8px
- Отступы от краев экрана: не менее 16px
- Размер шрифта: не менее 16px для основного текста

## Адаптивные особенности

### Анимации и переходы:
- Все анимации плавные и с плавным ускорением
- Для пользователей с "reduce motion" отключаются анимации
- Переходы между состояниями: 0.3 секунды

### Доступность:
- Все элементы интерфейса доступны через клавиатуру
- Поддержка фокуса навигации
- Адаптивные размеры шрифтов для чтения
- Семантическая разметка HTML

### Тестирование:
- Проверка на всех устройствах и браузерах
- Тестирование с различными размерами экранов
- Проверка на доступность и удобство использования
